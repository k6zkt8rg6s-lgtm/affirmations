# Как разместить приложение по https

---

## ВАШИ ССЫЛКИ — сохраните, чтобы не искать

**Приложение:**
`https://k6zkt8rg6s-lgtm.github.io/affirmations/`

**Обновить** (перетащить файлы и нажать Commit changes):
`https://github.com/k6zkt8rg6s-lgtm/affirmations/upload/main`

**Репозиторий целиком:**
`https://github.com/k6zkt8rg6s-lgtm/affirmations`

### Порядок обновления

Собрали `python3 build.py` → открыли вторую ссылку → **выделили в папке
`web` все файлы разом** и перетащили → внизу **Commit changes** → через
минуту готово. Карточки при этом не трогаются.

**Перетаскивайте всю папку, а не один `index.html`.** Раньше здесь было
написано «обычно меняется только index.html» — и это подводило.

Почему. Рядом со страницей лежат ещё два файла, от которых зависит само
обновление:

- `version.txt` — одна строка с отметкой сборки. По ней приложение и
  узнаёт, что на сайте лежит версия новее. Не обновили его — приложение
  будет уверять, что у вас последняя версия, сколько бы новых страниц вы
  ни положили рядом.
- `sw.js` — обработчик, который хранит приложение в памяти устройства.
  Пока не изменится он сам, устройство может неделями отдавать
  сохранённую копию страницы и не заглядывать на сайт.

Файлов всего семь, и лишними они не будут: одинаковые перезапишутся
теми же самыми.

### Если обновление всё равно не приходит

1. Откройте приложение → «⋯» → **Обновить приложение**. В окне теперь
   написаны обе версии: ваша и та, что лежит на сайте. Если они разные —
   нажмите «Обновить», приложение вычистит память и заберёт свежую.
2. Если написано, что версии одинаковые, — значит, на сайт новая версия
   не легла. Проверьте, что Commit changes нажат и прошла минута-другая.
3. Проверить сайт, минуя всякую память устройства, можно так: откройте
   адрес приложения в **частном окне** Safari (Файл → Новое частное
   окно). Там нет ни сохранённой копии, ни обработчика — видно ровно то,
   что лежит на сайте.

После этого приложение будет работать одинаково на MacBook и на iPhone:
надёжное хранение, микрофон, иконка на экране «Домой», работа без интернета.

Нужен адрес вида `https://…`. Ниже — бесплатный способ через GitHub Pages,
без Терминала.

## Шаг 1. Завести GitHub

1. Откройте `github.com`, нажмите **Sign up**, заведите бесплатный аккаунт.
2. Подтвердите почту.

## Шаг 2. Создать место для файлов

1. Нажмите **+** справа вверху → **New repository**.
2. Имя: `affirmations` (латиницей, без пробелов).
3. Выберите **Public**.
4. **Create repository**.

Публичным будет только код приложения. Ваши карточки туда не попадают —
они остаются на устройстве.

## Шаг 3. Загрузить файлы

1. На странице репозитория нажмите **uploading an existing file**.
2. Перетащите в окно шесть файлов из папки `web`:

   `index.html`, `manifest.webmanifest`, `sw.js`,
   `icon.svg`, `icon-180.png`, `icon-512.png`

   Файл `.nojekyll` в папке скрытый и **не нужен** — он страхует от
   случая, когда имена файлов начинаются с подчёркивания, а у нас таких
   нет. Не ищите его.

   Файл `КАК-РАЗМЕСТИТЬ.md` загружать тоже не обязательно.
3. Внизу нажмите **Commit changes**.

## Шаг 4. Включить публикацию

1. Вкладка **Settings** → слева **Pages**.
2. В разделе *Build and deployment*: Source — **Deploy from a branch**,
   Branch — **main**, папка — **/ (root)**. **Save**.
3. Подождите 1–2 минуты и обновите страницу. Появится адрес вида:

   `https://ваше-имя.github.io/affirmations/`

## Шаг 5. Установить на MacBook

Чтобы на компьютере это тоже было приложением с иконкой, а не вкладкой:

1. Откройте полученный адрес в **Safari** на MacBook
2. Меню **Файл** → **Добавить в Dock…**
3. Название — «Аффирмации» → **Добавить**

Появится иконка в Dock. Запускается отдельным окном, без адресной строки,
со своим значком в переключателе программ. Микрофон работает.

Если пункта «Добавить в Dock» нет — у вас macOS старее Sonoma.
Тогда просто держите вкладку в Safari, всё работает так же.

## Шаг 6. Открыть на iPhone

1. Откройте этот адрес в **Safari** на iPhone.
2. Кнопка «Поделиться» → **На экран «Домой»**.
3. Запускайте с иконки. Адресной строки не будет, приложение откроется
   на весь экран и заработает без интернета.

Микрофон на iPhone спросит разрешение при первой записи — разрешите.

## Шаг 7. Перенести карточки на iPhone

Размещение по https **не связывает устройства между собой**. Карточки
по-прежнему хранятся отдельно: свои в браузере на Mac, свои на iPhone.
Открыв адрес на телефоне впервые, вы увидите пустое приложение — это
нормально.

Чтобы перенести карточки:

1. На **MacBook**: кнопка **↻** вверху → **↑ Сохранить в файл**.
   Сохранится файл `affirmations-sync.txt`. Положите его в папку
   iCloud Drive.
2. На **iPhone**: кнопка **↻** → **↓ Взять из файла** → выберите этот
   файл (iCloud Drive виден в окне выбора как обычная папка).
3. Приложение покажет, что внутри. Нажмите **Загрузить в приложение**.

Загрузка ничего не стирает — добавляются только те карточки, которых
на устройстве ещё нет. Голосовые записи переносятся вместе с текстом.

Так же и в обратную сторону: сделали карточку на телефоне — сохранили
там, взяли на Mac.

### Почему файл `.txt`, а не `.json`

Раньше файл назывался `affirmations-sync.json`, и на iPhone его нельзя
было выбрать: в окне выбора он показывался серым. Это поведение самой
iOS — она гасит файлы тех типов, которые не умеет открывать, и никакие
настройки на стороне приложения этого не меняют. Обычный текстовый файл
система открывать умеет, поэтому выбирается свободно. Внутри лежит ровно
то же самое.

Старые файлы `.json`, сохранённые прежней версией, приложение по-прежнему
читает — переделывать их не нужно.

### Если файл всё равно не выбирается

В окне синхронизации внизу есть строка **«Не получается выбрать файл?»**.
Разверните её, откройте файл на другом устройстве, скопируйте всё
содержимое и вставьте в поле. Так переносятся тексты, цвета и избранное;
голосовые записи этим способом не переносятся.

## Обновление приложения

Репозиторий заново создавать не нужно — просто заменяете файлы.

Замените **все файлы из папки `web`**, а не один `index.html`. Вместе со
страницей меняются `version.txt` (по нему приложение узнаёт, что вышло
новое) и время от времени `sw.js` (он хранит приложение в памяти
устройства). Оставите их прежними — устройство может так и не узнать,
что на сайте появилась новая версия.

1. Откройте свой репозиторий на GitHub
2. **Add file** → **Upload files**
3. Откройте папку `web` на MacBook, выделите в ней все файлы (Cmd+A) и
   перетащите в окно GitHub
4. Внизу — **Commit changes**

GitHub заменит совпадающие по имени. Через минуту обновление доедет. На
устройствах приложение подхватит новую версию при следующем открытии с
интернетом; если ждать не хочется — «⋯» → «Обновить приложение».

**Карточки при обновлении не пропадают.** Они лежат в браузере на
устройстве и с файлами приложения никак не связаны.

## Что стало доступно и чего не было в файловой версии

| | Файл двойным щелчком | По https |
|---|---|---|
| Карточки, цвета, избранное | да | да |
| Голосовые записи | нет | **да** |
| Надёжное хранение на iPhone | ненадёжно | **да** |
| Иконка на экране «Домой» | нет | **да** |
| Работа без интернета | да | **да** |

## Безопасность после публикации

Публикуется только код. Ваши карточки и записи никуда не уходят:
правило `connect-src 'none'` запрещает браузеру любые запросы наружу —
приложение физически не может ничего отправить.

Обработчик офлайн-режима кеширует только собственные файлы приложения
и работает по правилу «сначала сеть, потом кеш»: при наличии интернета
всегда приходит свежая версия, старая не залипает.

Если по адресу зайдёт посторонний, он увидит пустое приложение со своими
данными. Ваших карточек там нет — они лежат в браузере на вашем устройстве.
