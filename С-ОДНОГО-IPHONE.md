# Как сделать всё с одного iPhone

Без компьютера. После настройки приложение работает офлайн, запись голоса
доступна, данные не пропадают.

## Почему без размещения не обойтись

Микрофон браузер выдаёт только защищённой странице — адресу, который
начинается с `https://`. Это правило Apple, обойти его нельзя: ни файлом
из «Файлов», ни через AirDrop, никак.

Поэтому один раз нужно получить адрес. Дальше — всё с телефона и без сети:

- **Микрофон** — работает, потому что адрес защищённый
- **Офлайн** — приложение сохраняется целиком при первом открытии
- **Данные не пропадают** — приложения, добавленные на экран «Домой»,
  не подпадают под правило Safari, которое стирает данные обычных сайтов
  через 7 дней без посещений

Настройка занимает минут десять и делается один раз.

---

## Шаг 1. Проверить, что файлы на телефоне

Откройте **Файлы** → **iCloud Drive** → `cloude code` → `affirmations`
→ `web`.

Должны быть шесть файлов:

`index.html`, `manifest.webmanifest`, `sw.js`,
`icon.svg`, `icon-180.png`, `icon-512.png`

Если папки нет — значит iCloud ещё не докачал её на телефон. Подождите,
когда компьютер будет включён и в сети.

## Шаг 2. Завести GitHub — прямо в Safari

1. Safari → `github.com` → **Sign up**
2. Почта, пароль, имя пользователя латиницей
3. Подтвердите письмо из почты

Бесплатно, карта не нужна.

## Шаг 3. Создать место для файлов

1. Сверху **+** → **New repository**
2. Repository name: `affirmations`
3. Выберите **Public**
4. **Create repository**

Публичным будет только код приложения. Ваши карточки и записи туда
не попадают — они остаются в телефоне.

## Шаг 4. Загрузить шесть файлов

На телефоне страница GitHub показывается в упрощённом виде. Если кнопки
загрузки не видно:

> Нажмите **ᴀA** слева в адресной строке → **Запросить сайт для
> настольного компьютера**

Дальше:

1. На странице репозитория: **Add file** → **Upload files**
2. **choose your files** → откроется выбор файлов
3. Внизу **Обзор** → **iCloud Drive** → `cloude code` → `affirmations`
   → `web`
4. Нажмите **Выбрать**, отметьте все шесть файлов, подтвердите
5. Внизу страницы — **Commit changes**

## Шаг 5. Включить публикацию

1. Вкладка **Settings** (может быть спрятана под «…»)
2. Слева в списке — **Pages**
3. *Source*: **Deploy from a branch**
4. *Branch*: **main**, папка **/ (root)** → **Save**
5. Подождите 1–2 минуты, обновите страницу

Появится адрес:

```
https://ваше-имя.github.io/affirmations/
```

## Шаг 6. Установить на экран «Домой»

1. Откройте этот адрес в **Safari**
2. Кнопка «Поделиться» внизу → **На экран «Домой»** → **Добавить**
3. Закройте Safari, запускайте с иконки

Теперь это отдельное приложение: без адресной строки, на весь экран.

## Шаг 7. Проверить, что всё работает

1. Откройте любую карточку
2. Нажмите красную точку **●** вверху — iPhone спросит разрешение
   на микрофон, разрешите
3. Скажите пару слов, нажмите **■**
4. Внизу карточки появится **▶** — послушайте

Затем включите авиарежим и откройте приложение снова — оно должно
открыться и работать. Это значит, офлайн-режим встал.

---

## Дальше компьютер не нужен

Создавать разделы, колоды, карточки, записывать голос, отмечать
избранное — всё с телефона. Интернет не требуется.

Интернет понадобится только если однажды захотите обновить само
приложение: тогда нужно будет заменить файлы в репозитории.

## Что стоит знать

**Резервная копия.** Данные лежат в телефоне. Если удалить приложение
с экрана «Домой» или очистить данные Safari — карточки пропадут.
Раз в пару недель нажимайте **↻** → **Выгрузить** и сохраняйте файл
в iCloud Drive. Голосовые записи в копию не входят: они слишком тяжёлые
для текстового файла.

**Если позже захотите пользоваться и на MacBook** — откройте там тот же
адрес. Но карточки будут отдельные: браузеры на разных устройствах
не связаны. Переносить их — той же кнопкой **↻**.

**Приложение не следит за вами.** Правило `connect-src 'none'` запрещает
браузеру любые запросы наружу. Даже если бы в коде была ошибка,
отправить ваши записи некуда — некому и незачем.
